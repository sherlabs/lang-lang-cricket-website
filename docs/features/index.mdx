Every user-facing feature of the Lang Lang Cricket Club site has one file in this folder. Each file says who it is for, why it was built, what it does, how the committee uses it and what is deliberately left out. Deferred work is tracked in GitHub issues #2 to #37 and summarised in issue [#38](https://github.com/sherlabs/lang-lang-cricket-website/issues/38).

## How to add a feature doc

1. Copy any existing file and change the slug (kebab-case, `docs/features/<slug>.mdx`).
2. Fill in the frontmatter: `title`, `status: shipped`, `routes`, `collections`, `admin`, `owner`, `related`, `added`.
3. Keep the five headings exactly: Persona, Why it was built, What it does, How to use it, Not included / deferred.
4. Describe only what is built, checked against the code. Link deferred work to its GitHub issue.
5. Add a row to the right table above. `tests/feature-docs.test.ts` fails if a file is missing a key or heading, if the index does not link every file, or if a `related` slug does not exist.
6. Update the doc in the same pull request whenever the feature's behaviour changes.
