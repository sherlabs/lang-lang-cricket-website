## Persona

- **A player's grandparent** who wants every result of last season for one grade.
- **A club historian** looking for "all games against Pakenham" and the scorecard for each.

## Why it was built

`/fixtures` shows the current season. The BetterStats feature set (`2026-10-03-betterstats-features-design.md`, A10) added a browsable archive of finished games across the seasons PlayHQ lists, linking each game to its existing scorecard.

## What it does

- Finished games only, newest first, grouped by round, for any season PlayHQ lists (Summer 2023/24 onwards; the page says older history does not exist).
- Filters (GET form, so they work without scripts): season, grade, opponent text (`q`) and result (all, won, lost, drawn or other). Each row links to `/fixtures/[gameId]`.
- Paged by rounds (6 rounds per page, `?page=`). If no grade is chosen and the season has more than 200 finished games, only the first page is shown with a "narrow by grade" hint.
- It reuses the PlayHQ loaders and their cache, so it fans out to each team's fixture list and relies on the 30 minute cache; failures show the "PlayHQ unavailable" panel.
- Includes junior grades, as `/fixtures` does. Filtered views are marked `noindex`; the unfiltered page has a canonical URL.

## How to use it

Visit `/matches`, choose a season, then narrow by grade, opponent or result. No admin steps.
