## Persona

- **The site admin** who wants a first draft of the season write-up.
- **The president** who reads and corrects it before it goes on the club's yearbook.

## Why it was built

Writing "the season in a paragraph" is the part nobody gets to ([#12](https://github.com/sherlabs/lang-lang-cricket-website/issues/12)). A draft from the numbers saves the blank page, as long as it is never published unread and never invents anything.

## What it does

- **Season summary** is a plain text field on a yearbook (6,000 characters, blank line between paragraphs), shown on the public yearbook as "The season in review". An editor can simply write it by hand.
- **Draft a season summary** (admin only) asks an AI through the Vercel AI Gateway for about 300 words and fills the field in the form. Nothing is saved until the form is saved, and the field is marked *AI-assisted draft, please check*. *Discard AI draft* clears it.
- **What the AI is told:** the season's record and results by grade from the stored matches, the leaders already shown on the public yearbook (visible players), the highest individual scores of visible players, the premiership line and the honours entered for that season. It never receives opposition player names, emails, phones, bios or hidden players. The facts go in a delimited data block and the prompt says the block is data, never instructions (honours and opposition names are free text). The AI is told to use only those facts.
- **Never auto-published.** An AI-drafted summary cannot be published until someone ticks *I have read and corrected this text*; editing the text un-ticks it, a new draft resets it, and the ticking user is stored for the record. Deleting the text (or discarding the draft) clears the AI mark and never blocks publishing.
- **Public note.** An AI-assisted summary shows "Written with AI assistance" (`club.pageCopy.yearbooks.aiNote`). It does not claim anyone checked it. The text is rendered as text, never HTML.
- **Off until configured.** With no `AI_GATEWAY_API_KEY` (or the Vercel OIDC token on Vercel) the button is disabled ("AI drafting is not set up on this site") and the endpoint answers 503 without any network call. The model is `YEARBOOK_AI_MODEL` or the default in `config/site.ts`.
- **Limits.** About 600 output tokens, a 30 second time-out, and one site-wide counter of drafts per day (`AI_DAILY_DRAFT_LIMIT`, default 20) incremented atomically. A failed call does not use up a draft. The Gateway's own spend limit is the backstop.

## How to use it

1. An admin opens the yearbook, saves it, and presses **Draft a season summary**.
2. Read the text, correct anything wrong (the AI can still be wrong), tick **I have read and corrected this text** and save.
3. Set the status to Published.

## Not included / deferred

- No per-yearbook cooldown, no streaming, no drafts for other content, no automatic regeneration. The draft sees only the data above, so a season without stored matches gets a short, thin draft.
- The key is set in the host's environment, never in a file in the repository. Tracking issue: [#38](https://github.com/sherlabs/lang-lang-cricket-website/issues/38).
