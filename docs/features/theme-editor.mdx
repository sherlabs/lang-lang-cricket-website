## Persona

- **A designer or developer-admin setting the site up for a club**, who wants the club's colours, crest and heading font without touching code or rebuilding.
- **A visitor or committee member**, who sees the same colours on the public site, the admin and the shared player cards.

## Why it was built

This repository is reused for other cricket clubs, so no club-specific colour may live in code (issue [#14](https://github.com/sherlabs/lang-lang-cricket-website/issues/14), tracking issue [#38](https://github.com/sherlabs/lang-lang-cricket-website/issues/38)). Lang Lang's values became the seed defaults, so the Lang Lang site looks the same as before.

## What it does

- A `theme` global (admin write, public read) holds **five main colours** (dark, accent, light section, body text, secondary text), **seven other shades** (raised dark, accent darker, lighter, pale tint and deep, card fill, caption), a **crest** upload and a **heading font**. All twelve colours are entered directly as hex (a three-digit value is expanded and stored in capitals).
- The colours reach the page as twelve `--brand-*` CSS variables (rendered by `components/theme-style.tsx` in the public layout and in the admin layout). Tailwind keeps the `brand-*` class names (`bg-brand-gold/40` still works), so no markup changed. Saving revalidates the whole layout, so the site updates within seconds.
- The same variables drive the keyboard focus ring, text selection, the event placeholder art, card shadows and the admin (primary buttons, cream background, the green-to-gold success ramp, which is mixed in CSS from the accent shades). The admin ramp's in-between steps differ from the old fixed values by at most 2 per colour channel; that is the only admin-visible change.
- **Heading font**: a fixed menu of five bundled faces (Barlow Condensed, the default and previous face; Oswald; Bebas Neue; Anton; Playfair Display), all SIL Open Font License, served from `assets/fonts` with no network call at render. Body text stays Inter. The menu is fixed because the fonts must be bundled; `assets/fonts/README.md` says how a face is added.
- **Crest**: the uploaded crest, else the logo in Club details (kept as a fallback, no data move), else the bundled crest. One function (`resolveTheme`) decides, and the menu, footer, structured data, admin sign-in and stat card all read it.
- **Live sample**: above the readability list the form shows a sample (dark band with accent text and buttons, light band with body text, chips and card fills) and a swatch row with each hex, all recoloured as the designer types. **Suggest the other shades** fills raised dark, accent darker, lighter, pale and deep and the card fill from the accent, dark and light-section colours (`lib/theme/derive.ts`; the deep accent is darkened until it reads on white and on the pale tint), and every field stays editable. **Revert to last saved** reloads the form after a confirmation.
- **Readability check**: the form shows a live list of colour pairs with their contrast ratios. Required pairs (body text on white, on the light band, on card fills and on the pale tint; secondary text on white, the band and card fills; deep accent text on white, the pale tint, the band and card fills; dark label on the accent; white, accent and light accent on the dark colour and on the raised dark colour) must reach 4.5 to 1 or the save is refused with a message naming the colours involved and saying which way to move them. Advice-only pairs (captions, the accent against white) show as "Check". Lang Lang's own seed has two known advice items (captions on card fills at 4.47, and the gold against white).
- With no saved theme the Lang Lang seed renders, so an unseeded database looks right. `seed:club`, `seed:demo` and the ETL club step write the seed only if it was never saved.
- Image routes use `themedImageResponse()` (`lib/theme/og.tsx`), which loads the theme fonts and the crest; the player stat card is the reference ([Stat cards](./stat-cards.mdx)). A new image route must list `./assets/fonts/**` in `outputFileTracingIncludes` in `next.config.ts`.
- Per-club values read before the database exists (canonical host, PlayHQ organisation and team prefix, export file prefix, cookie prefix, timezone, locale) stay in environment variables through `config/site.ts`; see [Multi-club template](./multi-club-template.mdx).

## How to use it

1. Sign in as an admin, open **Advanced > Site look (colours and fonts)**.
2. Type the five main colours, then press **Suggest the other shades** (or type each shade yourself).
3. Read the readability list; fix any row marked "Too low" (they stop the save).
4. Upload a transparent PNG (or JPEG) crest, at least 512 pixels tall, and choose a heading font. The crest picker offers only PNG and JPEG files because the shared player cards cannot draw SVG or WebP; if a crest cannot be loaded for a card the server logs a warning and the card uses the bundled crest.
5. Save, then reload the home page and the admin. To go back, set the Lang Lang values again or ask a developer to run `pnpm seed:club --only theme --force`. That resets the colours and the heading font only; plain `--force` would also overwrite Club details (name, copy, SEO, links) with the seed.
6. Local preview of a second look: `pnpm seed:demo --target 127.0.0.1/langlang_dev --confirm --theme-sample blue` (writes a blue palette, overwriting a saved theme).

**How to verify (developers).** Capture before and after screenshots with headless Chrome against a seeded local database and compare them:

```sh
pnpm dev -p 3601   # local DB seeded with seed:demo and fixture:stats
for each of /, /stats, /players/<slug>, /events at widths 1280 and 390:
  "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --disable-gpu --hide-scrollbars \
    --force-prefers-reduced-motion --virtual-time-budget=8000 --window-size=<w>,2600 \
    --screenshot=<dir>/<name>-<w>.png http://127.0.0.1:3601<path>
node scripts/shot-diff.mjs <beforeDir> <afterDir>   # passes at 0.05 percent of pixels or fewer
```

Warm each URL with `curl` first (a cold dev compile can outlast the time budget). `/fixtures` is excluded because it calls live PlayHQ.

## Not included / deferred

- No light or dark finish: the public dark block is unused and a real dark mode needs role-based surface variables across the whole class set. It is a later issue (not opened yet; the owner of #14 should open it).
- No draft preview of the real site before saving (the in-form sample is only an approximation): a valid but ugly palette goes live immediately. The contrast check, admin-only access and the reset steps above are the safeguards.
- No native colour picker on the hex fields (the sample and swatch row show the colour instead), no preview of a saved-but-unpublished look, and no free-text fonts. The heading font is not preloaded unless it is Barlow Condensed: `next/font` decides preloading at build time, so the chosen face loads on demand (display swap). Favicon, share image and hero stay files or Club details uploads.
- Tracking issue: [#38](https://github.com/sherlabs/lang-lang-cricket-website/issues/38).
