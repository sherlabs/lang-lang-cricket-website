## Persona

- **A volunteer secretary** who should be told in plain words if the stats did not update, and what is waiting for approval.
- **The site admin** who wants the counts and a link to the sync runs.

## Why it was built

Failures were only visible in the Sync runs list, which volunteers never open ([#11](https://github.com/sherlabs/lang-lang-cricket-website/issues/11)).

## What it does

- Replaces the "Needs your attention" block on Home with one short list built from data that already exists:
  - **The latest PlayHQ update.** Committee: "Player stats were updated last night." (or "last updated <date>" when older than a day and a half; "being updated right now"), or, when it failed, "Last night's stats update did not finish. The site is still showing the previous numbers. Please tell the site administrator." Raw errors are never shown to editors.
  - **Waiting for approval:** stories and photos, with links.
  - **Admins also see** the error text, the counts (matches saved, matches that did not save, players whose match totals disagree with their season totals) with a link to Sync runs, the number of possible duplicate players, and the import log (how many imports are on the site and when the latest was).
- Problems come first; "You are all caught up" shows only when nothing needs attention.
- The wording lives in `payload/admin/copy.ts`.
- **No "milestones crossed" line.** Counting crossings from match rows would use the wrong baseline (milestones start from season totals) and a rolling window would announce one crossing on seven nightly runs. The existing Milestones widget stays on Home.

## How to use it

Open **Home**. Follow a link to act on an item. An admin who sees the "did not finish" line opens **Sync runs** or presses **Run sync now** under Advanced.

## Not included / deferred

- No email or push notification, and no new milestone computation. A correct "new milestones" line would compare `player-seasons` totals before and after each sync, which needs a stored snapshot; it is not built. Tracking issue: [#38](https://github.com/sherlabs/lang-lang-cricket-website/issues/38).
